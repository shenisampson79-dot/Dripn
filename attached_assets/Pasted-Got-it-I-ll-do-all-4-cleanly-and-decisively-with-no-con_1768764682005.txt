# 1️⃣ DFY Lite Delivery Experience (what the user actually experiences)

## Goal

Create **maximum perceived value** while:

* Avoiding wardrobe creation
* Avoiding user editing
* Avoiding scope creep

---

## Structure: “14-Day Style Plan”

### What the user sees

* A **14-day view**, not “3–5 outfits”
* Each day shows:

  * “Today’s look”
  * Weather/context note
  * Why it works

Behind the scenes:

* 3–5 core outfits
* Variations created by:

  * Layering
  * Shoe swaps
  * Accessories
  * Jacket on/off

**Psychology:**
They feel styled *every day*, not “sold 3 outfits”.

---

## Allowed user actions

* 👍 Love this
* 👎 Not me
* 🗣 “Adjust this” (text input)
* ⭐ Save outfit (static card)

## NOT allowed

* Editing items
* Swapping pieces
* Adding clothes
* Seeing item lists

---

## Editing (important clarification)

* **Only the stylist edits**
* Edits = regeneration / refinement
* Language used:

  > “Tell me what feels off — I’ll fix it.”

Never call it “editing”.
